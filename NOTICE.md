# Notice

This is an initial repository scaffold for a design-first Java CORBA ecosystem.

No third-party implementation source code has been copied into this repository.
Reference implementations such as JacORB, Eclipse GlassFish CORBA ORB, JBoss
OpenJDK ORB, and ACE/TAO are to be used only as clean-room behavioral references
and interoperability peers unless a future legal review explicitly permits other
use.
