# Local Specification Cache

This directory is for local working copies of official specification PDFs used
while closing traceability gaps. The PDFs are intentionally ignored by Git.

Use this cache only as a reading aid. Requirement, design, and implementation
work must still cite the canonical references in
`docs/specification-traceability.md` and `docs/standards-baseline.md`.

Do not copy source code or implementation logic from reference ORBs or other
implementations into this repository.
