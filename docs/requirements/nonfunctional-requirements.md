# Nonfunctional Requirements

| ID | Requirement | Status |
|---|---|---|
| REQ-NFR-001 | The implementation shall be generated-code-first and closed-world friendly. | draft |
| REQ-NFR-002 | Core runtime behavior shall not require runtime bytecode generation. | draft |
| REQ-NFR-003 | Reflection shall be absent from core protocol, CDR, GIOP, IIOP, IOR, ORB, and POA modules unless an ADR grants a narrow exception. | draft |
| REQ-NFR-004 | All network input shall be bounded before allocation. | draft |
| REQ-NFR-005 | Build outputs shall be reproducible where technically feasible. | draft |
| REQ-NFR-006 | Public compatibility APIs and modern APIs shall remain separate artifacts. | draft |
| REQ-NFR-007 | Every implemented feature shall update its conformance matrix. | draft |
| REQ-NFR-008 | Every published artifact shall be usable independently where its dependency graph allows. | draft |
