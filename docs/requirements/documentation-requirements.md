# Documentation Requirements

| ID | Requirement | Status |
|---|---|---|
| REQ-DOC-001 | Every public API package shall have `package-info.java`. | draft |
| REQ-DOC-002 | Every published module shall have module documentation once JPMS metadata is introduced. | draft |
| REQ-DOC-003 | Every public class and public method in published artifacts shall have Javadoc. | draft |
| REQ-DOC-004 | Protocol code shall document bounds, invariants, and spec references. | draft |
| REQ-DOC-005 | Generated code shall include source IDL, generator version, mapping mode, and compatibility profile. | draft |
| REQ-DOC-006 | Every implementation PR shall update relevant docs or explicitly justify why no documentation changed. | draft |
