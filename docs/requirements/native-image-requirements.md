# Native Image Requirements

| ID | Requirement | Status |
|---|---|---|
| REQ-NATIVE-001 | Representative clients, servers, tools, and services shall run as GraalVM Native Image executables. | draft |
| REQ-NATIVE-002 | Normal stubs, skeletons, codecs, and operation descriptors shall be generated at build time. | draft |
| REQ-NATIVE-003 | Native-image metadata shall be deterministic and reviewed like source code. | draft |
| REQ-NATIVE-004 | Runtime class initialization policy shall be documented for every module that participates in native-image builds. | draft |
| REQ-NATIVE-005 | Native tests shall cover `idlj`, client, server, naming server, and selected interop fixtures. | draft |
