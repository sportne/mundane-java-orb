# Agent Handoff

This repository is ready for coding agents only after the following are approved:

1. G0 charter and standards baseline.
2. G1 requirements.
3. G2 architecture docs.
4. G3 verification plan.
5. G4 build infrastructure.
6. G5 empty-module validation.

## First safe agent tasks

Before runtime implementation, agents may work on:

- filling exact specification clause IDs in conformance matrices;
- validating Gradle wrapper generation;
- completing dependency verification metadata;
- adding documentation link checks;
- writing additional ArchUnit rules;
- improving offline-build validation scripts;
- expanding interop peer manifests.

Runtime/protocol/compiler implementation tasks must wait for G6.
