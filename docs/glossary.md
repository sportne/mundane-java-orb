# Glossary

| Term | Meaning |
|---|---|
| CDR | Common Data Representation, the wire encoding used by GIOP/IIOP. |
| GIOP | General Inter-ORB Protocol. |
| IIOP | Internet Inter-ORB Protocol, the TCP/IP mapping of GIOP. |
| IDL | Interface Definition Language. |
| IOR | Interoperable Object Reference. |
| ORB | Object Request Broker. |
| POA | Portable Object Adapter. |
| DII | Dynamic Invocation Interface. |
| DSI | Dynamic Skeleton Interface. |
| DynamicAny | Dynamic runtime representation for Any values. |
| Native Image | GraalVM ahead-of-time compiled native executable. |
| Compatibility profile | A controlled set of behavior switches and conformance expectations for a CORBA version or deployed ORB family. |
| Golden-wire test | A test that asserts exact protocol bytes. |
| Clean-room note | A behavioral observation of a reference implementation that does not copy implementation code. |
