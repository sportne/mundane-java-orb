# mundane Java ORB 1.0.0

This release publishes GitHub Release assets only. It does not publish to
GitHub Packages, Maven Central, or any other remote Maven repository.

## Release assets

- `mundane-java-orb-1.0.0-maven-repository.tar.gz`: a staged Maven repository
  containing the project publications under the `io.github.mundanej` group.
- `mundane-java-orb-1.0.0-published-artifacts.txt`: the planned publication
  coordinate summary produced by `./gradlew printPublishedArtifacts`.
- `mundane-java-orb-1.0.0-SHA256SUMS.txt`: SHA-256 checksums for the release
  assets.

## Verification baseline

- The non-optional G10 interoperability matrix completed before this release:
  `basic-idl`, `object-reference`, `naming`, `giop`, `iiop`, and `rmi-iiop`
  passed across JacORB, JBoss OpenJDK ORB, Eclipse GlassFish CORBA ORB, and
  ACE/TAO for JVM and Native Image local lanes.
- The release workflow validates `./gradlew test`, `./gradlew
  validateDesignControlPack qualityGate`, and `./gradlew
  offlineReleaseValidation` before creating the GitHub Release.
- The release tag must be `v1.0.0`, matching `corba.version=1.0.0`.

## Deferred scope

Optional CORBA Services remain separately human-gated. Trading, Event,
Notification, Transaction, Security, and Time Service behavior is not promoted
by this release asset workflow.
