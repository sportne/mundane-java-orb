# POA Design

## Concepts

- POA path.
- POA manager state.
- lifespan policy.
- ID assignment policy.
- servant retention policy.
- request processing policy.
- implicit activation policy.
- thread policy.
- active object map.
- servant manager.
- servant locator.
- adapter activator.

## Implementation policy

The POA is a policy-driven state machine. A POA policy-combination matrix must be
completed before implementation begins.

## Initial profile

A constrained POA-lite can be implemented first, but only after the full POA
policy matrix has been documented and staged.
